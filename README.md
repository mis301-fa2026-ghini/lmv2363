# Side Quest Coffee Co.

A two-page informational website for Side Quest Coffee Co., a fictional neighborhood coffee shop and tabletop gaming community space in Juniper Falls, Texas. Created for the Hands On Tech HTML assignment.

## Pages

- **Home (`index.html`):** Café introduction, all seven days of business hours, contact information, food and drink menu with prices, and recurring events.
- **The Game Shelf (`games.html`):** Eight games with their supplied player counts and approximate play times.

Both pages share `style.css` and include navigation between Home and The Game Shelf. The site uses HTML and CSS only, with no JavaScript or back-end functionality.

## Setup

1. Place `index.html`, `games.html`, `style.css`, and `README.md` at the top level of the GitHub repository.
2. Add the two AI-generated images to a folder named `images`, using the exact filenames listed above. Images are not included with the code downloads.
3. Check that the image descriptions in the HTML `alt` attributes accurately describe your images.
4. Commit the files with a meaningful message, such as `Add initial Side Quest website`.
5. Follow the assignment's GitHub Pages instructions to publish from the `main` branch and the root folder.
6. Open the published site and verify both pages, navigation, styling, images, and business information against the assignment.

For a local preview, keep the files and images together and open `index.html` in a browser. Complete the assignment's final checks on the published website as well.

## Scope

This website presents information only. Online ordering, payments, event registration, accounts, searchable inventory, and live game availability are outside the project scope.

The address, telephone number, and email address are fictional assignment data and are intentionally preserved as supplied.
